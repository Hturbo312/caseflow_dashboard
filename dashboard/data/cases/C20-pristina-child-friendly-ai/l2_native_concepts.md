## 2. 原生概念盘点

### 2.1 NC-C20-001 儿童主导的AI辅助公共空间共创（复合概念）

| 字段 | 内容 |
|---|---|
| 编号 | `NC-C20-001` |
| 标签 | 儿童主导的AI辅助公共空间共创 |
| 候选类型 | action |
| 定义 | 儿童在 facilitator 支持下，使用 AI 可视化工具参与公共空间的需求表达、选址、愿景和方案评估；专业设计师把儿童输入转译为方案。 |
| 案例内示例 | 2023-06 中旬 AI 共创 session；2023-09-14 前最终评估工作坊；儿童用 mood board/AI 平台表达空间想法。 |
| 来源关系 | R014、R016、R020、R021、R023、R024、R025、R029、R031、R032、R056 |
| 频次 | 11 条关系 |
| 主要证据 | M01-E03、M01-E09、M01-E10；M03-E01；M10-E02；M11-E01 |
| 边界疑问 | 这是“儿童参与 + AI 使用 + 设计转译”的复合概念。若整体映射到单一共享概念，会把 AI 与儿童参与两个语义成分混在一起；G2 应先拆分。 |
| 处理建议 | 保留为复合伞概念；新增 `NC-C20-006`（儿童主导的公共空间共创）与 `NC-C20-007`（AI 辅助的空间想法生成与可视化）作为可映射子概念。 |
