## 3. C19 的 `SC-C19-102` 与 C20 的重复候选

### 3.1 现有候选

| 字段 | 内容 |
|---|---|
| 编号 | `SC-C19-102` |
| 标签 | 生成式AI参与式可视化 |
| 类型 | technology |
| 定义 | 以参与者口述或文本提示驱动生成式 AI，实时生成场所营造图像并支持反复修改。 |
| 范围 | 生成式图像工具/实践；不含传统GIS、3D建模或预设图库。 |
| 负例 | 仅展示预设图、无参与者提示。 |
| 支持案例 | C19 |
| 支持原生概念 | `NC-C19-02 AI文本生成图像参与` |
| 状态 | `candidate_single_case` |

### 3.2 与 C20 的关系

- C20 的 `NC-C20-007 AI辅助的空间想法生成与可视化` 描述儿童使用 UrbanistAI 生成/可视化空间想法；语义与 `SC-C19-102` 高度重叠。
- C19 的 `NC-C19-02` 是 technology；C20 的 `NC-C20-007` 是 action。类型不同，但共享概念 `SC-C19-102` 描述的是“生成式AI参与式可视化”这一技术/实践，C20 提供了第二个使用案例。
- 因此，G2 提出的 `SC-C20-01 AI辅助的空间想法生成与可视化` 与 `SC-C19-102` 构成近重复；**建议撤回 SC-C20-01**，改为：
  - `NC-C20-007` → `SC-C19-102` `partial_or_approximate`（原生行动 vs 共享技术）；
  - 同时保留 `NC-C20-007` → `SC-C01-131` `partial_or_approximate`（更宽的工具类别）；
  - 给 `SC-C19-102` 增加 C20 支持，使其成为 C19+C20 两案例候选，提交 G4 决定是否晋升为 `researcher_confirmed`。
