# C20 共享概念候选（L2-G2）

> 状态：待研究者确认；均为单案候选，不确认正式共享概念。
> 版本：`L2-C20-v0.1`

## 1. 候选

### SC-C20-01 AI辅助的空间想法生成与可视化

| 字段 | 内容 |
|---|---|
| 类型 | action |
| 定义 | 儿童或参与者在facilitator支持下使用AI平台生成/可视化空间想法，并将其带入讨论、筛选与设计转译的行动。 |
| 范围 | 只含AI生成/可视化在参与过程中的使用；不含工具本身、模型能力、生成效果或最终建成。 |
| 负例 | 仅用CAD/手绘出图；AI生成但未进入参与过程；无儿童/居民参与的内部方案生成；把AI输出直接当作最终方案。 |
| 支持案例 | C20 |
| 支持原生概念 | NC-C20-007 |
| 来源关系 | R020、R021、R029、R031、R032、R033 |
| 证据 | M01-E09；M03-E01；M10-E02；M11-E01 |
| 状态 | `candidate_single_case` |
| 边界 | 无提示词/生成日志；不能证明AI对最终方案的影响；不能把“使用”写成“效果”。 |

### SC-C20-02 儿童地方知识转译

| 字段 | 内容 |
|---|---|
| 类型 | action |
| 定义 | 把儿童对安全、隐私、绿色社交空间的地方经验与需求，转译为选址、空间要素与设计方案的行动。 |
| 范围 | 只含儿童地方知识进入设计转译；不含一般社区需求识别、成人代述或未进入设计的意见收集。 |
| 负例 | 一般社区需求调查未进入设计；成人代替儿童表达；仅收集意见未转译；把儿童引语直接当设计依据。 |
| 支持案例 | C20 |
| 支持原生概念 | NC-C20-002 |
| 来源关系 | R003、R004、R056 |
| 证据 | M01-E05、M01-E06、M01-E07、M01-E09 |
| 状态 | `candidate_single_case` |
| 边界 | “转译”是分析性概括；没有正式需求—设计要素对应表，不能证明每个需求都被采纳。 |
