## 三条阅读边界

1. **论文效果是作者报告**：渗透率、活跃峰值、信息耗时、工单响应、线下互动等数字均未独立验证。
2. **APP 不等于小程序**：同一名称与团队不能证明同一技术载体；两者在冻结关系中保持分离。
3. **扩展期活动不等于持续运行**：2025-10/11 的开放日使用只证明一次校社活动中的使用陈述。
