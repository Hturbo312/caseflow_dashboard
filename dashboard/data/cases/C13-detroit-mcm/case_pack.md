## 1. 案例概览

| 项 | 内容 |
|---|---|
| case_id | `C13` |
| 名称 | 底特律 Motor City Mapping 全市地块普查与空置建筑数据平台 |
| 英文 | Motor City Mapping (MCM), Detroit |
| 时段 | 2013-09 – 2015-12（核心 2013-09 – 2014-12；2015 平台整合与外部扩展） |
| 技术影响观察期 | 2016-01 – 2017-12（未重建，仅有 2015-09 平台快照） |
| 空间 | 底特律市域约 139 平方英里、380,233 个地块；Highland Park / Hamtramck 为方法扩散 |
| 证据截止 | 2026-11-13 |
| 研究问题 | 数据生产、技术—能力—行动、分类装置、开放数据与参与、技术影响的持续性与衰减 |

**一句话**：DBRTF 在联邦行动与破产背景下，借助 D3/Loveland 的 Blexting 完成全市 37.8 万个地块普查，把破败从估算变成 84,641 个可排序地块，并通过 MCI/SATT、公开平台与社区复核，把数据转成拆除优先级与公共信息基础设施。
