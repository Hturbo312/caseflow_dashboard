# C12 Eastserve 案例知识包

本目录保存 Eastserve（东曼彻斯特）案例从 G0 到 G6 的候选内容、审核包、研究者决定与修改记录。

## 目录

- `case_scope.md`：G0 案例边界（当前 v0.1 候选）
- `materials/`：已获取的原始材料（PDF/HTML）
- `extracted/`：从原始材料提取的纯文本，便于定位
- `review/`：每个 gate 的 Review Packet 与决定日志
- 后续：`materials.md`、`evidence.md`、`process.md`、`facts.md`、`relations.md`、`case_pack.json`

## 状态

- 当前 gate：G0
- 当前状态：等待研究者确认，未进入 G1
- 证据截止：2026-11-13

## 规则

- 所有 AI 输出均为候选；研究者确认后才冻结。
- 每个 gate 的 packet 未获 `yes` 前，不开始下一阶段。
- 不覆盖历史版本与审核记录。
