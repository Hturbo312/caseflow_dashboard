## 2. 来源结构与独立性

| 类型 | 材料 | 作用 |
|---|---|---|
| 一手项目/政策文件 | M02、M06 | 计划目标、产出、治理、交付模式 |
| 独立评估 | M03 | 实施问题、参与、结果调查、目标偏差 |
| 学术研究 | M09、M14 | 技术架构、覆盖数据、治理与可持续性分析 |
| 政府/欧盟案例库 | M10 | 项目自述、资助、调查数据、后续阶段 |
| 全国/地方媒体 | M01、M04、M07、M08、M11、M13 | 时间锚点、人物引述、价格与规模、国际关注 |
| 政策评论 | M05 | 无线技术架构与“适当技术”论述 |
| 官方登记/网页存档 | M12、M15 | 组织存续、品牌转换、退出 |

**独立性判断：**
- M03 为独立评估，可作为结果核查的主锚点。
- M06 为 DfES 委托的项目总结，但与项目方关系较近，不能替代独立评估。
- M10 属“良好实践”案例，绩效数字可能由项目方提供，需与 M03/M09/M14 交叉。
- M07、M08、M11 为地方媒体，适合时间、人物、价格与规模，不适合单独确认因果。
- M14 为学术分析，但 2006 年数据为二次引用，需回查原始统计。

## 3. 质量核验

### 3.1 文件完整性

- M02：21 页 PDF，文本可提取；页脚含 2003-03-10 文档管理日期，正文标题日期为 2001-07-09，登记时以正文日期为准并注明差异。
- M03：190 页 PDF，文本可提取；双栏排版需按 `sort=True` 读取，已生成纯文本。
- M06：32 页 PDF，文本可提取；部分页面为双栏，已生成纯文本。
- M09：17 页 PDF，文本可提取。
- M14：22 页 PDF，文本可提取；Crossref 核验书名为 *Measuring E-government Efficiency*，2014，pp. 191–212。
- M01/M04/M05/M07/M08/M10/M11/M15：HTML 已保存；M04 仅预览，M11 日期待核。
- M12/M13：以页面文本保存，非原始 HTML；M13 仅首段。

### 3.2 重复与重叠

- M03 与 M06 都覆盖 WuC 计划目标，但 M03 是独立评估、M06 是项目总结，保留两者。
- M07、M09、M10、M14 都出现“3,500 台 PC/3,500 户”类数字，口径可能不同，G2 不合并，逐条记录限定。
- M10 与 M14 都出现“1,500 户宽带/2,000 名用户”，时间与定义不同，保留为不同证据。
- M01 与 M02 都描述 450 户试点，但 M01 是发布报道、M02 是后续计划回顾，保留两者。

### 3.3 已知日期问题

- MEN 旧文普遍带 `2013-01-12` 站点迁移时间；M07、M08、M11 的“更新”时间不能当事件时间。
- M11 正文提及 Beverley Hughes 任 Minister for the North West（约 2007–2009），故登记为“约 2009”，待 G2 进一步核。
- M02 页脚 `10/03/2003` 与封面 `9th July 2001` 不一致，属文档管理/打印日期，登记采用封面日期。

## 5. 证据缺口（G1 结论）

1. Eastserve1 的启动文件、资金规模、450 户实际完成情况。
2. 2003 年无线宽带网络正式启用的同期项目稿或新闻。
3. 2007–2009 年用户数、覆盖率、收入与成本数据。
4. 2011–2015 年服务交接、用户流失、网络维护与退出决策文件。
