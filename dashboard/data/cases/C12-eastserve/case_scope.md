## 2. 事件边界草案

### 2.1 建议纳入的核心过程

1. **2000–2001：Eastserve1 试点与 eastserve.com 上线。** 在 New Deal for Communities（NDC）与 Single Regeneration Budget（SRB5）框架下，面向 Beswick、Clayton、Openshaw 启动试点，建设社区接入点、向约 450 户提供设备与联网，并于 2001 年 3 月正式发布社区门户。
2. **2001–2003：Wired Up Communities（WuC）第二阶段与家庭规模化部署。** 以“设备 + 3 小时培训 + 本地内容 + 社区支持”的组合，按 Clayton → Openshaw → Beswick 分阶段入户；2002 年夏引入无线宽带，替代/补充拨号接入。
3. **2003–2006：无线网络运营、内容与 e-government 服务扩展。** 覆盖学校、UK Online/社区学习中心；housing、street lighting 等报修与本地就业信息进入门户；形成居民小组、社区冠军、ITEM 安装与就业链条。
4. **2006–2010：可持续性与体制转换。** 从 NDC/公共项目转向以服务收入和社会企业/私营合作维持；2009 年成立 Symera Eastserve Ltd，2010 年推出预付费 Wi-Fi，计划当年完成覆盖。
5. **2011–2017：服务延续、组织退出与基础设施转移。** 既有用户与网络继续运行，但组织载体连续失败：Symera Eastserve 于 2010 年进入清算，CityServe (999) 于 2011 年进入清算、2013 年解散；2014 年 ITS 收购并升级网络；2016 年 eastserve.com 转向 Cityserve 品牌；Symera Eastserve Ltd 于 2017 年正式解散。本阶段不与 2000–2010 的核心实施机制混写。

### 2.2 建议排除或降为背景的内容

- 曼彻斯特全市数字战略、MDDA、ONE-Manchester：仅作为制度情境，不作为本案行动主体。
- IntelCities 的 e-government 平台与工具研发：仅在与 Eastserve 实际服务直接相连时纳入。
- New East Manchester 的物理更新（住宅拆除、Commonwealth Games 场馆与道路等）：仅作为情境与因果背景，不纳入本案行动链。
- 其他六个 WuC 试点（Liverpool Kensington、Alston CyberMoor、Brampton、Carpenters Estate、Blackburn East、Framlingham）：仅用于跨案例比较，不纳入本案事实集。
- 2016 年后 eastserve.com 转向 Cityserve 品牌及 2017 年公司解散：纳入 B 方案的“2011–2017 服务延续与影响衰减”阶段，但不并入 2000–2010 的核心实施链。

### 2.3 空间范围

- 核心区：Beswick、Clayton、Openshaw（NDC/SRB5 范围）。
- 扩展区：更广的 New East Manchester；材料中出现“6 平方英里”“9,000 户”“1,100 公顷”等不同口径，需在 G1/G3 逐条核定，不先合并。
- 不把“East Manchester”泛称为整个曼彻斯特市。

## 3. 纳入 / 排除标准

### 3.1 材料纳入标准

1. 直接描述 Eastserve 的项目设计、实施、治理、技术、参与、结果或退出。
2. 提供可定位的 Eastserve 数据（户数、设备数、培训人数、覆盖率、价格、时间）。
3. 属于同期政策/项目文件、独立评估、学术研究、地方或全国媒体报道、公司登记记录。
4. 网页材料须有可追溯 URL；优先保留原始页面或 Wayback 快照。

### 3.2 材料排除标准

1. 仅泛论“数字鸿沟”而未涉及 Eastserve 的文献。
2. 无法定位原文或仅有二手转述且无独立信息增益的内容。
3. 纯营销宣传且无法与项目文件/评估互证的绩效表述，只可作为“报道/观点”记录，不作为已实施事实。
4. 与本案无直接关系的曼彻斯特其他数字项目。

## 4. 研究问题草案

1. 在既有住宅区更新与 NDC 再生计划中，Eastserve 如何把“家庭设备、培训、本地内容、社区支持”组合成一套数字包容干预？各要素在实施中如何被调整？
2. 无线宽带作为替代性“最后一英里”基础设施，在什么条件下被采用？它如何改变覆盖、价格、服务能力与可持续性？
3. 居民小组、社区冠军、ITEM 等参与机制在不同阶段承担什么角色？产生了哪些可核验的参与、技能与就业结果？
4. 从公共项目转向社会企业/私营合作（Symera）时，哪些组织能力、用户关系和公共服务功能被保留、转移或削弱？

## 6. 来源冲突与边界风险（G0 已知）

1. **起始时间**：项目“2000 年设立”有多个二手来源，但具体月份与 Eastserve1 的正式启动时间尚缺一手文件。
2. **户数口径**：450 户（试点）、4,500 户（WuC 目标）、9,000 户（网络覆盖）、2,200 户（2002-09 安装）、3,500 户（2004 报道）、1,500 户宽带（2006）等分别指目标、覆盖、安装与付费用户，不能合并为一个“受益户数”。
3. **培训人数**：RR389 正文称约 2,500 人参加课程，摘要称 1,500 人接受培训；需在 G2 标为争议或按统计口径拆分。
4. **“欧洲最大/英国最大”**：2003/2005/2010/2013 均有类似表述，属报道性评价，需保留来源与时间，不写成客观排名事实。
5. **2013 年报道日期**：MEN 多篇旧文带“2013-01-12 更新”站点迁移时间；Symera 报道正文提及 Beverley Hughes 任 Minister for the North West（约 2007–2009），不能直接按 2013 年记为事件时间。
6. **案终时间**：Symera 公司 2017 年解散不等于 Eastserve 服务在 2017 年停止；2016 年已出现 Cityserve 品牌。需研究者决定是否把退出过程纳入核心。

## 7. 研究者确认结果（2026-11-13）

| 决策点 | 研究者决定 |
|---|---|
| 时间边界 | 采用 **B：2000–2017**；其中 2000–2010 为核心实施，2011–2017 为服务延续与影响衰减 |
| 试点纳入 | 纳入 Eastserve1（约 450 户、10 个社区接入点） |
| 空间边界 | 核心限定为 Beswick、Clayton、Openshaw；更广 New East Manchester 作扩展/结果 |
| 退出过程 | Symera（2009–2010）、Cityserve（2016）、公司解散（2017）纳入“影响衰减/退出”阶段 |
| 研究问题 | 采用草案 4 问，并增加“技术影响的持续性与衰减”假设 H-C12-01 |
