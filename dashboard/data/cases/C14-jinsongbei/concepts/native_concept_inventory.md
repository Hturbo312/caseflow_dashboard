## 3. 边界疑问

**NC-C14-01 五方联动**
- 与一般跨组织协作的区别是什么？
- 是否必须同时包含五类主体，缺一是否仍成立？
- 与“党建共同体”的边界如何划分？

**NC-C14-02 双过半与先尝后买**
- 与一般居民协商/方案共制的区别是什么？
- 双过半是否是必要条件？
- 先尝后买是否独立于双过半？

**NC-C14-03 微利可持续**
- 是条件、模式还是结果？
- 与一般成本约束的区别是什么？
- 投资与回收期的三种口径如何裁定？

**NC-C14-04 低效空间长期运营权**
- 与一般空间施工/运营的区别是什么？
- 长期运营权是否是核心条件？
- 是否必须包含租金/合同安排？

**NC-C14-05 物业+养老**
- 与一般养老服务、物业服务的区别是什么？
- 是否必须由物业主导？
- 服务清单与响应记录是否足以支撑概念？

**NC-C14-06 HEDATA智慧社区平台**
- 平台功能/覆盖/使用未验证，是否足以立概念？
- 与社区门户、行政平台、数据中台的区别是什么？
- 是否应作为企业运营平台的特例？

**NC-C14-07 智能车棚**
- 是设备、设施还是空间？
- 是否联网、计费、接入消防/物业平台？
- 与一般充电桩的区别是什么？

**NC-C14-08 爬楼机/电动轮椅租借**
- 是设备还是服务？
- 数量覆盖多个社区，如何限定？
- 使用记录缺失是否影响概念成立？

**NC-C14-09 社区党建共同体**
- 与五方联动的关系是什么？
- 是组织、机制还是行动？
- 是否应并入五方联动？

**NC-C14-10 责任规划师沉浸式设计**
- 与一般规划设计/公众参与的区别是什么？
- “沉浸式设计”是否可复制？
- 是否应作为规划方法还是协作机制？

**NC-C14-11 社区共建者与手机班**
- 是数字素养、社区活动还是智慧治理？
- 是否使用平台/设备？
- 是否应并入技术能力建设？

**NC-C14-12 智慧社区六维度**
- 是目标框架、传播话语还是评估标准？
- “智慧”维度是否有技术清单？

**NC-C14-13 智能门禁与人脸识别**
