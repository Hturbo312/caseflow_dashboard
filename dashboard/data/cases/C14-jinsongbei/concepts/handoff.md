# C14 向 cross-case-causal-analysis 的交接

## 1. 版本

- L1 案例包：`case_pack.md` / `case_pack.json`（v1.0）
- L2 概念层：`L2-C14-shared-v1.0`
- 审核记录：`review/decision-log.md`

## 2. 可交接内容

- 62 个原生实体、69 条关系、58 条事实、56 条证据、7 个过程段落。
- 14 个原生概念（`concepts/native_concept_inventory.json`）。
- 20 条概念映射、10 个单案例候选、2 个 `no_map`（`concepts/concept_mapping_v1.0.json`）。
- 共享概念层：64 个节点（46 已确认 + 18 候选）；777 条映射。
- 证据指针：`evidence.md` / `evidence.json`；案例包内含完整指向。

## 3. 使用规则

- 比较走共享概念层；解释回到原生层与证据层。
- 10 个 `SC-C14-10x` 均为单案例候选，不得当作已确认共享概念使用。
- `SC-C14-110`（企业运营的社区智慧治理平台）证据仅企业方陈述，比较时需标注弱证据。
- 投资三条（3000万/45%、2.9亿、4000余万）为 `disputed`，不得合并为单一数值。
- 适老化子图与智慧治理主图分列；不得把爬楼机/轮椅/扶手/呼叫器自动归入智慧治理。
