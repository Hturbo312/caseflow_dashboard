# C14 L2 概念层

本目录保存 C14 向 `scalable-concept-framework` 交接的原生概念、映射、候选与版本记录。

## 文件

- `native_concept_inventory.md` / `.json`：14 个原生概念盘点（G1）
- `concept_mapping.md` / `.json`：20 条映射、10 个候选、2 个 `no_map`（G2 候选）
- `concept_mapping_v1.0.md` / `.json`：G4 发布版映射
- `shared_concepts_v1.0.json`：10 个单案例候选
- `network_update.md`：G3 增量网络更新
- `ontology_delta_v1.0.json` / `.md`：G4 本体增量
- `version_record.md` / `.json`：版本记录

## 版本

- 当前版本：`L2-C14-shared-v1.0`
- 基线：54 个节点（46 已确认 + 8 C13 候选）
- 更新后：64 个节点（46 已确认 + 18 候选）

## 规则

- 单案例只产生候选，不确认正式共享概念。
- 部分映射只映射有依据的语义成分。
- 不修改既有概念定义、范围、负例与 `supporting_case_ids`。
