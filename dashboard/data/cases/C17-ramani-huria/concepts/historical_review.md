# C17 Ramani Huria 历史映射回查（L2-G3 v0.1）

> 目的：为 7 个新候选寻找第二案例支持；检查是否影响既有概念边界。
> 范围：C01–C11（57 个原生概念）、C12（12 个）、C14（14 个）。C13/C15/C16 尚无概念层，列后续回查。

| 候选 | 最接近的原生概念 | 为何不足以支持 | 结论 |
|---|---|---|---|
| SC-C17-01 社区洪泛记忆的空间转译 | NC-C02-003 | C02 把居民语言与照片转为未来愿景，不处理历史洪水记忆，也不产出可建模几何。 | 无第二案例 |
| SC-C17-02 大学—社区联合外业制图 | NC-C02-005 | C02 是大学参与组织工作坊（actor），C07 是社区步行调查，均非学生督导制的外业制图。 | 无第二案例 |
| SC-C17-03 开放地理数据生产与发布 | NC-C01-003 | C01 生产地方数字内容，未形成开放地理数据或许可发布。 | 无第二案例 |
| SC-C17-04 基础设施网络数据模型 | 无 | 既有概念均无线性基础设施的拓扑 schema 或连通性规则。 | 无第二案例 |
| SC-C17-05 低成本移动采集工具组合 | NC-C12-10 | C12/C14 是入门培训或专业传感，不是“手机+免费应用+低成本定位”的采集组合。 | 无第二案例 |
| SC-C17-06 模型验证与迭代 | NC-C10-004 | C10/C11 是建筑能耗绩效监测，不涉及水动力模型输出校验与参数迭代。 | 无第二案例 |
| SC-C17-07 数据稀缺与基础地图缺失 | NC-C11-001 | C11 诊断建筑老化与能效，不涉及地图、排水或地形数据供给不足。 | 无第二案例 |

## 结论

- 7 个候选均未获得第二案例的原生实例支持，保持 `candidate`，不转为正式 `SC-xxx`。
- 未发现需要修改既有 44 个 C01–C11 候选或 C12/C14 已发布概念的边界冲突。
- 未新增历史映射：C13（MCM 居民普查）、C15、C16 尚无概念层，待其 L2 完成后回查是否可支持 SC-C17-02/05。
